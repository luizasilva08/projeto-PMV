# projeto-PMV

**ADEL ** — Sistema IoT para Monitoramento de Condições de Tráfego

**Descrição**

O projeto ADEL (Painel de Mensagens Variadas) consiste no desenvolvimento de um sistema embarcado baseado em Arduino, destinado ao monitoramento de variáveis ambientais e de deslocamento, com exibição de dados em tempo real, para apoio à segurança viária.

**Objetivo**

Fornecer informações sobre velocidade, temperatura, umidade, luminosidade e distância, com ajuste automático dos limites de velocidade conforme as condições de iluminação, visando à melhoria da segurança e da eficiência no tráfego.

**Tecnologias e Componentes**

Plataforma: Arduino UNO R3

Linguagem: C++

Sensores: DHT11, LDR e sensor ultrassônico

Saída: Display LCD I2C (16x2) e LED

**Funcionalidades**

Coleta e processamento de dados em tempo real

Cálculo de velocidade

Identificação de período (dia/noite)

Ajuste automático dos limites de velocidade

Exibição de informações e alertas no display
